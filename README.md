# Credit Card Approval Prediction

## Project Overview
This project predicts whether a credit card application is approved or rejected using Machine Learning.

## Algorithms Used
- Logistic Regression
- Decision Tree
- Random Forest

## Technologies
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML
- CSS

## Project Structure


## How to Run

Install dependencies

```
pip install -r requirements.txt

```

Run the application

```
python app.py

```

Open

```
http://127.0.0.1:5000

```
